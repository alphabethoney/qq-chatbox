# 项目进度与公开发布记录

更新日期：2026-10-13。项目版本标记为 1.1.0；本次为 GitHub 源码与文档更新，不发布 PyPI 包，也不更新线上机器人。

## 已实现

- **导出**：NTQQ SQLCipher 流式解密及校验、Protobuf 解析、JSON/TXT 导出、媒体查找与下载、消息 ID 增量与定时轮询、大库容错及会话级恢复。
- **选择性读取**：元数据优先的会话/类型/时间筛选、会话清单、查询计划检查，范围与导出水位绑定。
- **机器人**：人格对话与历史问答、CLI/HTTP/OneBot11 接入、hash/BM25 和可选语义向量、群聊范围隔离、档案与来源时间线、可选长期记忆和管理追踪。
- **同步**：时间水位和重读窗口、累计历史、可选差分页解密缓存、单私聊范围隔离、Windows 受保护离线快照、每日私聊独立同步及合并发布、显式计划任务注册脚本。
- **人格评测**：检索注入默认关闭，通过显式开关比较；固定虚构开发集/留出集，支持契约验证与人工评分。

## 已知限制与下一步

- 同步跳过 WAL；真实 QQ WAL、持续写入一致性和版本兼容性仍需独立验收。离线快照遇运行中 QQ、非空 WAL 或写句柄冲突时拒绝/跳过，不自动关闭 QQ，无 VSS。
- 差分页缓存仍需全库扫描；累计合并与索引构建仍是全量。重读窗口之外的迟到消息需全量补回。
- 导出恢复不是解密断点续传；并发导出、Web 管理界面尚未实现。
- 人格测试证明输入/出处等编排契约，不证明更像真人；真实回复质量需独立盲评。
- 身份占位符脱敏不等于聊天内容不出云；配置云端模型/向量服务时，应自行取得授权并评估文本传输范围。
- 下一步重点为真实环境兼容性、资源开销、单实例部署与任务运行验收，以及模型效果评估。
